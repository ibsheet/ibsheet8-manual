# getFocusedCol ***(method)***

> 시트 내에 현재 포커스된 셀의 열이름을 반환합니다.

### Syntax
```javascript
string getFocusedCol();
```

### Return Value
***string*** : 열이름

### Example
```javascript
//현재 포커스된 셀의 열이름을 반환합니다.
var row = sheet.getFocusedCol();
```

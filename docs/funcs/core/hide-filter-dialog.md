# hideFilterDialog ***(method)***
> 헤더에 필터 다이얼로그 아이콘을 숨깁니다.

### Syntax
```javascript
boolean hideFilterDialog();
```

### Return Value
***none***

### Example
```javascript
// 헤더행에 필터 다이얼로그 아이콘을 숨깁니다. 
sheet.hideFilterDialog();
```

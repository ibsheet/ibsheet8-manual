# getFocusedPage ***(method)***

> 현재 포커스가 위치한 데이터 [페이지 객체](/docs/appx/page-object)를 리턴합니다.

### Syntax
```javascript
object getFocusedPage();
```

### Return Value
***page object*** : [페이지 객체](/docs/appx/page-object)

### Example
```javascript
//현재 포커스가 있는 페이지 객체
var pageObj = sheet.getFocusedPage();
```

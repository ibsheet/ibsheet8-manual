# getEditRow ***(method)***
> 현재 편집 중인 행 객체를 반환합니다.

### Syntax
```javascript
object getEditRow();
```

### Return Value
***row Object*** : [데이터 로우 객체](/docs/appx/row-object)

var eRow = sheet.getEditRow();

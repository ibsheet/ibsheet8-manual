# 시작하기

`IBSheet8`은 별도 설치 없이 HTML, JavaScript, CSS만으로 동작하는 **JavaScript 데이터 그리드 컴포넌트**입니다.
대용량 데이터를 빠르게 처리하며, 조회·편집·저장, 엑셀 업로드·다운로드, 소팅·필터, 트리, 그룹, 피벗 등 업무 화면에 필요한 그리드 기능을 제공합니다.
주요 기능은 [제품의 특징](/docs/intro/feature)을 참고하세요.

좌측 검색창을 통해 각 함수,프로퍼티를 쉽게 검색할 수 있습니다.

# HintMaxWidth ***(cfg)***

<!-- synonyms: HintMaxWidth, hint max width, tooltip max width, hint width limit, hint size, 힌트 최대 너비, 힌트 너비, 툴팁 너비 제한, Hint MaxWidth, 힌트 크기 -->

> 힌트의 최대 너비(`px`)를 설정합니다.  

### Type
`number`


### Options

|Value|Description|
|-----|-----|
|`number`|힌트의 최대 너비|

### Example
```javascript
options.Cfg = {
    HintMaxWidth: 500 // 힌트의 최대 너비를 500px로 설정
};
```
